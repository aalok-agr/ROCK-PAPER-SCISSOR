# Rock Paper Scissors Web Game

A classic, interactive Rock Paper Scissors game built with core web technologies. This project features a clean User Interface, real-time score tracking, and responsive design.

## 🚀 Features
- **Interactive UI:** Smooth transitions and hover effects for player choices.
- **Real-time Logic:** Immediate result generation (Win/Loss/Draw) against a randomized computer opponent.
- **Scoreboard:** Tracks both the Player and Computer scores during a single session.
- **Responsive Design:** Optimized for both desktop and mobile viewing.
- **Reset Functionality:** Quickly clear the score and restart the game.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure of the game elements.
- **CSS3:** Custom styling, Flexbox layout, and UI animations.
- **JavaScript (ES6):** Game logic, event listeners, and DOM manipulation.
